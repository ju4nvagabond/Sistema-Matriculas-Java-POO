# 📚 Sistema de Matrículas - Java Swing & POO

Este es un proyecto práctico desarrollado en **Java** para aplicar los fundamentos de **Programación Orientada a Objetos (POO)** y el diseño de software basado en **Diagramas de Casos de Uso y Secuencia**.

## 🚀 Objetivo del Proyecto
El enfoque principal es la correcta separación de responsabilidades entre la capa de presentación (`IGU`) y la lógica de negocio (`Logica`), modelando entidades reales como Estudiantes, Directores y Asignaturas.

## 🛠️ Tecnologías
* **Lenguaje:** Java
* **Interfaz Gráfica:** Java Swing
* **Arquitectura:** Separación en paquetes (`IGU` y `Logica`)
* **Diseño:** UML (Diagramas de Casos de Uso y Secuencia)


## 💡 Aprendizajes Clave
* Traducción directa de diagramas UML a código estructurado.
* Gestión de eventos y flujos de usuario en aplicaciones de escritorio.
* Implementación de encapsulamiento, herencia y abstracción en POO.
